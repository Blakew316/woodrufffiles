Cameras
1. In Google Cloud, turn on the Smart Device Management API.
2. At console.nest.google.com/device-access, pay Google's one-time fee and create a project with the same client ID as Google Drive.
3. Paste its Project ID on the Cameras page and tap Save, then open Command center on the TV and scan the code.
Doorbell Alerts
Set this on one TV only. In the Device Access Console turn on Pub/Sub for your project, then in Google Cloud create a pull subscription to that topic and paste its full name. Connect the cameras again on the TV afterwards.

Share to TV
1. In Shortcuts, make a new shortcut and turn on Show in Share Sheet.
2. Add Get Contents of URL with the Share to TV link, Method POST, Request Body JSON with a field input set to Shortcut Input.
3. Name it “Send to TV”. Links open on the TV; text shows up as a message.
Announcements
Add Get Contents of URL with the announcement link, Method POST, Request Body JSON with the fields title and body. It shows on every TV.
